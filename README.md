# REACT

Horizon Europe research on rapid, environmentally sustainable responses to invasive agricultural fruit flies, particularly *Bactrocera dorsalis* (Bd) and *B. zonata* (Bz). REACT combines invasion-risk research, monitoring and detection methods, and Sterile Insect Technique strategies.

At RMCA, Task 1.4 investigates the population genomics and connectivity of *B. dorsalis* in La Réunion and *B. zonata* in Tel Aviv using whole genome sequencing and comparisons with geographically distributed reference populations.
